SAMI LAUNCH EXPERIENCE
======================

Primary launch-film URL after upload:
  /meet.html

Existing SAMI landing/install experience remains:
  /index.html

The final ASK SAMI button hands directly into index.html, so the existing browser-specific Add to Home Screen logic remains authoritative:
- Chromium-family browsers: native PWA install prompt where available.
- iPhone/iPad Safari: SAMI's compact Share > Add to Home Screen guidance.
- Already installed: existing SAMI logic can present Open SAMI.

The launch sequence is intentionally an interactive web film rather than a pre-rendered video. It stays sharp on phone/tablet/desktop, uses the existing SAMI brand assets, and avoids a second video download before the app.

Voiceover master script:
A lot goes into creating one site plan. Site visits. Photographs. Notes. Service information. Checks. Different sources. Different people. Then the information has to come together. A draft is created. Sent to CAD. Reviewed. Amended. Reviewed again. Approved. And when the project changes, parts of that process begin again. It takes time. It costs money. It creates journeys, duplication, and environmental impact. What if all of that could become simpler? One process. One team. One source of information. One tool. It's time to work smarter. It's time to Ask SAMI.

A separate AI voiceover was generated during production. It is not embedded in this flat package because the generator returned a hosted playback asset rather than a portable local master file. The film therefore uses timed on-screen narration plus the existing SAMI cinematic sound bed and remains fully self-contained.
